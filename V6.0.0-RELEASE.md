# Atelier Natália Huebra — V6.0.0

## Entrega

Esta versão evolui a base V5 para uma fundação de CRM administrativo sem quebrar o catálogo público existente.

### Alterações principais
- versão do projeto: `6.0.0`;
- novo arquivo padrão de dados: `data/atelier-v6.json`;
- migração automática de `data/atelier-v5.json` para V6 quando o banco V6 ainda não existir;
- login administrativo compatível com `/api/admin/login`;
- logout administrativo invalida a sessão;
- endpoint `/api/admin/stats`;
- configurações administrativas disponíveis por `/api/admin/settings`;
- atualização de registros por `PATCH` além de `PUT`;
- módulo administrativo de **Clientes**;
- módulo administrativo de **Agenda/Agendamentos**;
- CRM existente de leads preservado;
- auditoria preservada;
- health check atualizado para V6;
- smoke test automatizado V6;
- `package-lock.json` atualizado.

## Integrações futuras
A especificação SaaS enviada descreve uma plataforma maior, incluindo MySQL/PostgreSQL, Stripe, PIX, OAuth2/2FA, Redis, filas, analytics, S3, Twilio, SendGrid, WebSockets e CI/CD. Esta entrega não declara essas integrações como concluídas. Elas devem ser implementadas em etapas e testadas com as respectivas credenciais e ambientes.

## Testes executados
- `node --check server.js` — PASS
- `node --check public/app.js` — PASS
- `node --check public/admin/admin.js` — PASS
- `npm run check` — PASS
- `npm run build` — PASS
- `npm run smoke` — PASS

O smoke test cobre site público, `/admin`, health, login, cookie de sessão, configurações, clientes, atualização PATCH, agenda, estatísticas e logout.

## Instalação

```bash
npm ci
cp .env.example .env
# configurar ADMIN_EMAIL e ADMIN_PASSWORD
npm run check
npm run smoke
npm start
```

Para produção, não enviar `.env`, bancos locais, `.git` ou diretórios de backup.
